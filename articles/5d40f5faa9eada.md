## はじめに

今はWiMAXを使っています。紹介キャンペーンでStarlinkの端末が無料になったので、導入してみました。
「技術に触れる機会」として、体感ではなく数字で比較します。

## 比較の方針

### 性質の違い
| 観点 | WiMAX | Starlink |
|---|---|---|
| 通信方式 | モバイル回線(基地局経由) | 衛星経由 |
| 設置 | 置くだけ・持ち運びやすい | 空が開けた場所に端末を設置 |
| 電波の影響 | 建物・場所・混雑で変わる | 空の見通し・天気で変わる |

※制限条件や料金は変わるので、公式サイトで最新を確認して記入する。

### 比較する指標
ダウンロード速度、アップロード速度、遅延(ping)、時間帯によるばらつき

## 仮説(測る前に書く)

- 遅延は、衛星経由のStarlinkのほうが大きいのではないか
- 夜の混雑時間帯は、WiMAXのほうが速度が落ちやすいのではないか
- 上り速度は、Starlinkのほうが有利ではないか
- Starlinkは、天気の影響を受けるのではないか

## 計測方法

- 同じ場所・同じ端末で、回線を切り替えて計測する
- 朝・昼・夜の1日3回、数日間続ける
- 結果はCSVに追記し、あとで集計する

```python
import csv
import datetime
import speedtest  # pip install speedtest-cli

def measure(label: str, path: str = "results.csv") -> None:
    st = speedtest.Speedtest()
    st.get_best_server()
    down = st.download() / 1_000_000  # Mbps
    up = st.upload() / 1_000_000      # Mbps
    ping = st.results.ping            # ms
    now = datetime.datetime.now().isoformat(timespec="seconds")
    with open(path, "a", newline="") as f:
        csv.writer(f).writerow([now, label, round(down, 1), round(up, 1), round(ping, 1)])

if __name__ == "__main__":
    measure("wimax")  # Starlinkのときは "starlink" に変える
```

## 結果

### 平均
| 回線 | 下り(Mbps) | 上り(Mbps) | ping(ms) |
|---|---|---|---|
| WiMAX | 60 | 10 | 40 |
| Starlink | 150 | 20 | 45 |

### 時間帯別の下り(Mbps)
| 回線 | 朝 | 昼 | 夜 |
|---|---|---|---|
| WiMAX | 75 | 65 | 40 |
| Starlink | 160 | 150 | 140 |



## 試したこと(失敗含む)


1. WiMAXの設置・計測でのつまずきと工夫

・失敗（室内奥の電波減衰）： リビング中央のテレビ横に置いたところ、基地局からの電波が壁で遮られアンテナピクトが1〜2本に低下。下り速度が20〜35Mbps程度しか出ず、上りは5Mbps未満に落ち込んだ。
・改善策： スマホの電波測定アプリを併用しながら、最寄りの基地局が見通せる窓際へ移動。アルミレンジパネルを用いた自作リフレクターを背面に設置したところ、電波強度が改善し下り120〜160Mbpsまで向上。

Starlinkの設置・計測でのつまずきと工夫
・失敗（遮蔽物による微小な瞬断）： ベランダの手すりに仮設置した際、屋根の軒先と隣家の雨樋がアンテナの視野（北側上空100度）に数%干渉。Web閲覧時は気付かないものの、Zoom通話やオンライン会議で3〜5分おきに一瞬音声が途切れるパケットロスが発生。

・改善策： 公式アプリの「障害物スキャン機能」を使用し、空が100%抜けている屋根上にポールマウントを自作・固定して再設置。遮蔽率0%を確保した後は通話の切断が解消。

## 現時点の結論

全体的に屋外でも屋内でもStarlinkだと動画も遅延なく見れます。数百ビット出ているので日常的に使うインターネットの用途は満たされると思いました。
今後飛行機にも本格採用され、船旅とかにも何も気兼ねなくYoutubeなど見放題でLive配信なども行う世界線があるのではないでしょうか。

Starlinkは、現在、ホームプラン(最大300Mbps以上)の契約でStarlink Miniキットが無料(旧価格¥34,800)になるキャンペーン中で、試しやすい選択肢です。

**Starlink Miniの特徴**
- WiFiルーター内蔵で、ほぼA4サイズ・重量1.1kgと、かばんに入るポータブルさ
- 空が見える場所なら、どこでも通信できる
- 下りは最大100Mbps超
- IP67の防水防塵で、-30℃〜50℃の環境で動作する
- USB-C(100W、USB-PD)でも給電できる

使わなくなった場合も、将来のために手元に置いておけます。
